PERFECT CLEAN & STAY - VERSION WEB FINALE iPHONE / ORDINATEUR

Utilisation :
- iPhone : Safari, puis Ajouter à l’écran d’accueil.
- Ordinateur : Chrome ou Edge.
- Hébergement obligatoire en HTTPS.
- Même Supabase que l’application Android.

Partage médias :
- Catégories : un seul partage avec tous les médias + appartement + catégorie + items.
- État final : un seul partage avec toutes les photos + appartement + ÉTAT FINAL.
- Clés : un seul partage avec tous les médias + appartement + CLÉS + statut.
- Vidéo finale : un seul partage avec toutes les vidéos sélectionnées + appartement + VIDÉO FINALE.

IMPORTANT : la version Web demande un seul partage au système. La présentation finale en album et les limites de quantité restent décidées par iOS/Android/WhatsApp.
